# M7 — Plus

Status: **planned**

## Scope

From SPEC.md §2 and §6: RevenueCat for purchases and price experiments, the server knowing who
has Plus, Squad Boost, streak freezes, and the three paywall moments. The paywall already exists
(M1, StoreKit 2); M7 makes Plus real end to end.

Done when: a TestFlight sandbox purchase unlocks Plus in the app and on the server within a few
seconds (squad limits, custom lengths, Plus cosmetics, Deep Focus once approved), a refund or
expiry takes it away, Squad Boost shows on a squad with one Plus member, and a missed day spends a
freeze instead of breaking the streak.

## Purchases

- **RevenueCat SDK** (`purchases-ios-spm`) behind `PlusStore`, configured with the public API key
  from the build (`LK_REVENUECAT_KEY` in `Config/Local.xcconfig` / a CI secret). With no key the
  store keeps using StoreKit 2 directly, so builds without RevenueCat still work.
- `appUserID` = the server's user id once signed in (`Purchases.logIn`), anonymous before; signing
  out calls `logOut`.
- Products (App Store Connect, owner): `lockin.plus.monthly` A$3.99, `lockin.plus.yearly` A$24.99
  with a 7-day trial, `lockin.plus.lifetime` A$49.99 (non-consumable). RevenueCat entitlement
  `plus`; offering `default` with those three packages.

## Server

| Route | Body | 200 | Errors |
|---|---|---|---|
| `POST /webhooks/revenuecat` | RevenueCat's event | 200 | 401 without the shared `Authorization` value |
| `POST /me/plus/refresh` | | `{ user }` (asks RevenueCat's REST API for the caller, sets `plus_until`) | 503 `try_again` |

- Webhook events set `users.plus_until`: `INITIAL_PURCHASE`, `RENEWAL`, `PRODUCT_CHANGE`,
  `UNCANCELLATION`, `NON_RENEWING_PURCHASE` (lifetime → year 9999), `EXPIRATION`,
  `CANCELLATION` with a refund (→ now), `TRANSFER` (moves Plus between our user ids). Unknown
  `app_user_id`s (anonymous) are ignored. Secrets: `REVENUECAT_WEBHOOK_AUTH`,
  `REVENUECAT_SECRET_KEY`.
- **Squad Boost**: a squad with any Plus member is `boosted: true` in `GET /squads`; boosted pets
  can wear premium pet accessories (`fixtures/shop/catalogue.json` part `pet`), chosen by any
  member, shown to everyone (`p.k` gains an accessory: `"sprout.2.a3"`; `PetCode` already ignores
  what follows the stage).
- **Streak freezes**: each Plus member gets 2 a month (calendar month, squad time zone). When a
  squad's last counted day is the day before yesterday and a Plus member has one left, the gap day
  is filled with that member's freeze instead of the streak breaking (at most one gap per check).
  `streak` in `GET /squads` gains `frozenDays: ["YYYY-MM-DD"]` for the last 30 days, and `freezes`
  for the caller.

## App

- Paywall moments: (1) after the first completed squad session (once), (2) creating a second
  squad or adding a 5th member (the 402 `plus_required`), (3) tapping a Plus cosmetic, custom
  length or Deep Focus. Never at launch; never blocking a session.
- Settings: Plus status, Manage subscription (`showManageSubscriptions`), Restore.
- Squad detail: the Boost badge and the pet accessory picker for boosted squads; the streak shows
  frozen days with a snowflake.
- Custom session lengths (Plus): a stepper on Home's length picker, 5–240 minutes.

## Owner

RevenueCat project (App Store app, products, entitlement `plus`, offering `default`, webhook to
`https://<api host>/webhooks/revenuecat` with an Authorization value), App Store Connect
subscription group and products with prices, tax and banking agreements, sandbox testers.
