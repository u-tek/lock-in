# M1 — Solo lock-in (no backend)

Status: **done** (2026-10-14), apart from checks that need a real phone (below)

The owner's review of M0 (2026-10-14): "where is the actual app?" No onboarding, too much text,
too many options, developer screens in the main UI, no reason to use it and no sign of how it
makes money. M1 turns Lockin into an app someone would keep: onboarding, a creature, a real
session with its Live Activity, and Lockin Plus. Pulled forward on the owner's request: a first
onboarding pass (M6 polishes it) and the Plus paywall on StoreKit 2 (M7 adds RevenueCat, Squad
Boost and the paywall moments).

## Scope

- **Onboarding** (SPEC.md §1.1): pitch → make your Lockling → notifications → first 25-minute
  lock-in. Under a minute, one idea per screen, almost no words.
- **Home**: your Lockling, 25 / 50 / 90, one "Lock in" button, today's minutes, streak, coins.
  A Plus button. Nothing else.
- **Session**: full-screen timer with the Lockling focusing; Pause and End. Finishing celebrates
  and pays coins (1 per focused minute, +5 for finishing).
- **Live Activity**: Locklings instead of initials, in every presentation; Pause / Resume / End
  buttons in the expanded island and on the Lock Screen (`LiveActivityIntent`); spacing that
  follows Apple's island templates.
- **Lockin Plus** (SPEC.md §2): paywall with the plans and what Plus includes; StoreKit 2.
- **Settings**: Plus, notifications, about. Developer tools (APNs spike, Live Activity Lab,
  design tokens) are hidden: tap the version five times.
- Persistence: a small JSON store in the App Group (sessions, coins, streak, avatar). GRDB
  (SPEC.md §5.5) arrives when history needs queries (M5).

## The Lockling

Lockin's creature is a small padlock with a face: the shackle is its "hair". Locked in, the
shackle is closed; on a break or done, it pops open. Original to Lockin (not a bean, not a pet
from another app). Parts follow the avatar code `b<body>.c<colour>.e<eyes>.h<hat>`: bodies are
lock shapes, colours are system colours, eyes and hats are small SwiftUI shapes. Every state has
its own pose. Unknown parts draw as the defaults.

## Interfaces between modules

Written before the work so the modules can be built in parallel. Change them only together.

```swift
// Creature (extension-safe; Core, Model, DesignSystem)
public enum CreaturePose: String, CaseIterable, Sendable {
    case idle, focusing, onBreak, paused, done, left, slipped, celebrating
    public init(_ state: MemberState)            // focusing→.focusing, onBreak→.onBreak, …
}
public struct CreatureView: View {
    public init(avatar: AvatarCode, pose: CreaturePose = .idle, size: CGFloat)
}
public struct CreatureOption: Identifiable, Hashable, Sendable {
    public let id: Int          // the number in the avatar code
    public let name: String
    public let isPlus: Bool     // Plus-only cosmetic
}
public enum CreatureCatalogue {
    public static let bodies: [CreatureOption]
    public static let colours: [CreatureOption]
    public static let eyes: [CreatureOption]
    public static let hats: [CreatureOption]
    public static func colour(_ id: Int) -> Color
}

// LiveActivity (adds): intents shown as buttons in the activity. They run in the app's process.
public struct PauseSessionIntent: LiveActivityIntent { public init() }
public struct ResumeSessionIntent: LiveActivityIntent { public init() }
public struct EndSessionIntent: LiveActivityIntent { public init() }
@MainActor public final class SessionIntentBridge {
    public static let shared: SessionIntentBridge
    public enum Command: Sendable { case pause, resume, end }
    public var handler: ((Command) async -> Void)?   // set by the app at launch
}

// SessionEngine (app only; Core, Model, LiveActivity)
public struct SessionRecord: Codable, Hashable, Sendable, Identifiable {
    public let id: String
    public let startedAt: Date
    public let endedAt: Date
    public let plannedMinutes: Int
    public let focusedSeconds: Int
    public let completed: Bool
    public let coinsEarned: Int
}
public struct FocusStats: Codable, Equatable, Sendable {
    public var todayMinutes: Int
    public var streakDays: Int
    public var coins: Int
    public var completedSessions: Int
}
@MainActor public final class SessionEngine: ObservableObject {
    public enum Phase: Equatable, Sendable {
        case idle
        case running(startedAt: Date, endsAt: Date, plannedMinutes: Int)
        case paused(startedAt: Date, endsAt: Date, pausedAt: Date, plannedMinutes: Int)
        case finished(SessionRecord)
    }
    @Published public private(set) var phase: Phase
    @Published public private(set) var stats: FocusStats
    @Published public var avatar: AvatarCode            // saved when set
    @Published public private(set) var liveActivityProblem: LiveActivityError?
    public init(store: SessionStore = .appGroup(), liveActivities: LiveActivityController?, now: @escaping () -> Date = Date.init)
    public static func preview(phase: Phase, stats: FocusStats, avatar: AvatarCode) -> SessionEngine  // snapshots: no store, no ActivityKit
    public func start(minutes: Int)
    public func pause()
    public func resume()
    public func end()                       // early: records a partial session
    public func dismissFinished()           // .finished → .idle
    public func reconcile()                 // launch / foreground: finish if the time ran out
}
public struct SessionStore: Sendable {
    public static func appGroup() -> SessionStore
    public static func inMemory() -> SessionStore
}

// Paywall (app only; Core, DesignSystem, Creature)
public enum PlusPlan: String, CaseIterable, Identifiable, Sendable {
    case yearly, monthly, lifetime
    public var fallbackPrice: String        // "A$24.99", "A$3.99", "A$49.99"
}
@MainActor public final class PlusStore: ObservableObject {
    @Published public private(set) var isPlus: Bool
    public init(bundleID: String)
    public static func preview(isPlus: Bool = false) -> PlusStore   // snapshots: no StoreKit
    public func load() async
    public func displayPrice(for plan: PlusPlan) -> String
    public func purchase(_ plan: PlusPlan) async throws -> Bool
    public func restore() async
}
public struct PaywallView: View {
    public init(store: PlusStore, avatar: AvatarCode, onClose: @escaping () -> Void)
}
```

  `docs/decisions/0007-pet-out-of-expanded-island.md`.

## Risks

- **Creature at 20 pt.** The compact island leaves about 20 × 20 pt. The Lockling must read as a
  face at that size and in Always-On.
- **Intents.** `LiveActivityIntent` must be compiled into the app and the extension, and run in
  the app's process; the bridge only works once the app has set its handler.
- **StoreKit products** don't exist until the owner creates them in App Store Connect (M7 admin);
  until then the paywall shows the fallback prices and purchases fail politely.
- **The paywall sells features that don't exist yet** (Deep Focus is M8, Squad Boost M7, bigger
  squads M3). Fine for TestFlight; before App Review (M9) each must ship or be marked as coming
  soon, or Guideline 3.1.2 (state exactly what Plus includes) fails.
