## Scope

From SPEC.md §6:

- Repo, XcodeGen `project.yml`, `Makefile`, the `LKKit` package with the M0 modules, CI (build +
  tests) on GitHub Actions macOS runners, a server skeleton with tests.
- Apple setup (owner): App ID with Push Notifications (+ Broadcast capability for later), App

  iPhone. Result in `docs/spikes/apns-worker.md`.

## Risks

- **APNs from Workers.** APNs only speaks HTTP/2. If the Worker's outbound `fetch` can't reach
  it, only the sender moves to a small Node service (SPEC.md §4.2). The spike decides.
- **No Mac.** Every Swift build runs on CI; a compile error costs a CI round trip. Keep pushes
  small and the module tests fast.
- **Signing on CI.** TestFlight upload uses automatic signing with an App Store Connect API key;
  the key needs the Admin role so Xcode can create the distribution certificate in the cloud.
- **Family Controls approval** can take weeks; it gates M8 only, so request it now.
